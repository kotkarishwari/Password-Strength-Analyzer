# Password Strength Analyzer 🔐

A simple web-based Password Strength Analyzer that checks the strength of a password and provides suggestions to make it stronger.

## Features

- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Detects common passwords
- Detects repeated characters
- Detects simple sequences
- Provides password improvement suggestions
- Displays password strength score

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Enter a password in the password field.
2. Click on **Check Strength**.
3. The website checks the password.
4. It displays the strength and suggestions.
